# Supply Chain Operational Dashboard – Excel

## Overview

This project is an interactive **Supply Chain Operational Dashboard** built in **Microsoft Excel**.

The dashboard was created to monitor operational KPIs across distribution centers and product categories, using slicers and PivotTables for dynamic filtering.

The goal was to simulate a business reporting dashboard similar to what supply chain or operations teams use for performance tracking and decision-making.

---

## Dashboard Preview

Key dashboard sections include:

- **Fill Rate % KPI**
- **Unsaleable % KPI**
- **Fill Rate Trend by Week**
- **Fill Rate vs Unsaleable by Category**
- **Ordered Quantities by Mode**
- **Stores Ordered by Category / SKU**
- Interactive slicers for:
  - Date
  - Distribution Center
  - Category / Sub-category
  - Mode
  - Shipper
  - Grower

---

## Dataset

The dataset was created as a supply chain simulation and includes:

- Date
- Week / Quarter
- Distribution Center
- Category / Sub-category
- Mode
- Shipper
- Grower
- SKU
- Ordered Quantity
- Filled Quantity
- Unsaleable Quantity
- Total Cost
- Stores Ordered

Calculated KPI fields:

- **Fill Rate % = Filled Qty / Ordered Qty**
- **Unsaleable % = Unsaleable Qty / Ordered Qty**

## Key Insights

Example insights generated from the dashboard:

- Fill rate remained consistently above target in most weeks
- Certain categories showed higher unsaleable percentages
- Distribution center performance varied by category
- Product demand differed significantly by store group
- Filters made it easy to identify operational bottlenecks
